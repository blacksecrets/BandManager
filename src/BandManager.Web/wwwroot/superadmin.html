Spotify Web API checking...

  1. Go to the Spotify Developer Dashboard and log in with any Spotify account (free or paid both work).
  2. Click Create app. Give it any name/description - a Redirect URI is required by the form but never used here (this app only calls Spotify's search API with the app's own credentials, not a per-user login), so put in any placeholder like http://localhost/callback.
  3. Open the new app's Settings and copy the Client ID, then click View client secret to reveal and copy the Client Secret.
  4. Paste both below and save. This uses Spotify's Client Credentials flow (app-level access, no per-user Spotify login) - it can search tracks but can't do anything on anyone's actual Spotify account.

  2. Create an app and request access to the Addresses API.
  3. Copy the app's Consumer Key and Consumer Secret and paste them below.

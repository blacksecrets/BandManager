Automated Regression Tests

Black-box checks that log in as a dedicated, isolated test account and drive the real app the way a browser would - login, band switching, gig create/archive/unarchive, payout percentage validation, Travel trip saving, and more. These only exercise a fixed "Regression Test Band" that never touches Attica, Black Secrets, or any other real band. This catches things breaking that used to work - it does not replace clicking through the app yourself for new bugs or usability issues, which is what the checklist below is for.
